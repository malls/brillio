# BC-18: Store hardening: UTC-normalize ListedDate on write; idempotent schema_migrations bootstrap

Follow-up from BC-4 code review art_01M4W3X92E3R58R3C7QHCR8TXJ (PASS, two minor findings, deferred so they do not cost a re-review cycle). (1) backend/internal/store/listings.go: write listed_date with l.ListedDate.UTC().Format(domain.DateLayout) so a Listing built with a non-UTC location near midnight cannot store a different calendar date (seed.Load always yields UTC midnight today, matching the domain invariant). Small; can ride along with BC-5 if its owner touches the store.
